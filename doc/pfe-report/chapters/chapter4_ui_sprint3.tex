\subsubsection{Implemented web interfaces}
\label{subsubsec:impl-s3-ui}

\paragraph{Ask interface.}
The Ask workspace streams structured answers with confidence indicators and
clickable source citations grounded in retrieved chunks
(Figure~\ref{fig:seq-11}, Figure~\ref{fig:seq-12}).

\uiscreenshot{ui-ask-rag-chat.png}{Ask chat interface with structured answer, confidence indicator, and source citations}{Ask / RAG chat with citations}{fig:ui-ask-rag}

\paragraph{Answer feedback.}
Each completed assistant message offers copy, thumbs-up, and thumbs-down controls;
negative feedback can include a free-text comment for export and RAG evaluation
(Figure~\ref{fig:ui-ask-feedback}, Figure~\ref{fig:seq-14}).

\uiscreenshot{ui-ask-feedback.png}{Per-answer feedback controls with copy, thumbs up/down, and grounding badge}{Answer feedback controls}{fig:ui-ask-feedback}
