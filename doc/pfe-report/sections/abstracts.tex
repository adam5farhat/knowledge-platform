\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}

Organizations produce large volumes of internal documentation---policies, technical
guides, reports, and procedures---yet employees often struggle to find reliable
information quickly. Knowledge is scattered across storage systems, search remains
keyword-oriented, and access rules are difficult to enforce consistently. These
constraints slow decision-making and increase dependence on informal channels.

This report presents the \textbf{Knowledge Platform}, an enterprise web application
that centralises document management and provides intelligent search and
question-answering grounded in organisational content. The solution combines a
modern full-stack web architecture with hybrid retrieval techniques and
department-scoped access control, so users receive answers supported by traceable
sources rather than unsupported generated text.

The main contribution is a complete knowledge lifecycle: secure ingestion of
heterogeneous documents, semantic indexing, hybrid retrieval combining meaning-based
and keyword matching, streaming answers with citations, conversation history,
administrative governance, and user feedback to monitor answer quality over time.
The platform supports three organisational roles---Administrator, Manager, and
Employee---with permissions aligned to department structure.

The work was conducted at \CompanyName{} using an Agile Scrum methodology across
five development sprints. Validation combined automated integration testing,
repeatable deployment packaging, manual browser scenarios, and an evaluation
workflow for retrieval-augmented answers. Results indicate that the platform meets
its functional and non-functional targets while remaining suitable for iterative
improvement in a real organisational setting.
