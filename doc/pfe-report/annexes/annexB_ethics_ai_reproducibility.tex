\section{Declaration of generative AI usage}

Generative AI tools, including Cursor and large language model assistants, supported
this project in several ways: drafting and restructuring sections of this report
outline, suggesting LaTeX table structures aligned with the ESPRIM template,
implementing and debugging application code (notably the avatar CORP header fix),
and summarising technical documentation already present in the repository README.

All technical claims, test results, and architectural descriptions were verified
against the actual codebase, automated test output, and manual execution. The author
assumes full scientific and academic responsibility for the final submitted report.

reported results. Commands may be run from the repository root unless noted.
